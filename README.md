# PiiWipe

Drop a PDF, Word file, or text dump. Get a clean copy with emails, phones, SSNs, cards, and IPs blanked. Files never leave the browser.

Ask this answers: [Is there a tool that removes PII from documents before sharing them?](https://www.reddit.com/r/software/comments/1vpvzyg/is_there_a_tool_that_removes_pii_from_documents/)

- No account
- No upload
- Cap: 8 MB
- Heuristic wipe, not a legal redaction service

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```
